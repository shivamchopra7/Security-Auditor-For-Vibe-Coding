- **Map out your tech stack** 🕵️‍♂️

- **Audit dependencies & patch vulnerabilities** 🛠️

## Step-by-Step Guide: How to Use It

**Step 1: Summon your AI**
Open your favorite AI coding assistant (Cursor, Claude Code, Antigravity, etc.) in your target project's workspace.

**Step 2: Feed the Prompt**
Copy the entire contents of the [`Coding-Security-Auditor`](./Coding-Security-Auditor) file and paste it into your AI's context window.

**Step 3: Let the Magic Happen**
Watch as the AI creates a dedicated security branch (`security/audit-YYYY-MM-DD`) and sequentially executes the 7-task checklist precisely as instructed.

**Step 4: Review the Atomic Commits**
Your AI will commit each security phase individually, ensuring zero runtime breakage. It will leave inline comments (`// SECURITY-AUDIT:`) so you clearly understand the reasoning behind each change.

**Step 5: Check the Final Report**
At the end of the run, the AI generates a crisp `SECURITY-AUDIT-REPORT.md` outlining every vulnerability patched and detailing any remaining risks. Review, approve, and merge the branch when you're ready!
