# Security Policy

## Supported Versions

Currently, this repository provides an evergreen prompt for AI security auditing. The main branch (`main`) is the only officially supported version.

| Version | Supported          |
| ------- | ------------------ |
| v1.0.x  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within the prompt execution guide itself (e.g., if it mistakenly instructs the AI to bypass an important security check, or introduces an unsafe behavior), please report it immediately!

You can report vulnerabilities by:
- Opening a **Private Vulnerability Report** via GitHub (if enabled on the repository).
- Sending a direct message or email to the repository owner.

### Response Time
We strive to address critical issues within 48 hours. Upon acknowledging the vulnerability, we will work promptly to update the `Coding-Security-Auditor` prompt to eliminate the risk.

*Stay vigilant!*
